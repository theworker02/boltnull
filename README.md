# boltnull

Bolt encode/decode helpers for null payloads in pipelines.

**Site:** https://theworker02.github.io/boltnull/

## Install / run

```bash
git clone https://github.com/theworker02/boltnull.git
cd boltnull
node src/cli.js
node --test
```
